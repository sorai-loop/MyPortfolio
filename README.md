# sorai's portfolio
## 制作方針
AIに頼めばある程度のものが出てくる現代に全部手書きで尖ったポートフォリオを作る。
これが空彩來だ！！ってやつ。

訪問者の好奇心、期待に応える。
文字の色が変わるのにリンクじゃなかったりをしない。

訪問者に自身を売り込むことができる内容にする。stackのあいまいな評価やどこを頑張ったのかわからないworksを作らない。

また、初回なので面倒なものでも慣例があればそれに従う。
## 使用技術
- HTML
- CSS
- JavaScript
## 構成
1つのページで#をもちいたスクロール移動で項目を分ける。
- Name
- Works
- Article
- Stack
- Profile
    - About me
    - Activities
- Links
## 記述内容
### Name
名前、アイコンをでかでかと出して訪問者へ挨拶。
### Topics
Works、Article等からイチオシのものを持ってきて表示する。（2つほど）
### Works
制作物の一覧を日付の降順で表示。

各プロジェクトごとにプロジェクト名、軽い説明、使用技術についてを記述した要素を用意してグリッドで並べる。
要素をクリックすることで拡大表示？的な感じにしてさらに詳細な説明や動作動画、プロジェクトへのリンクを表示する。

Topicsに持ってきたいのでそれぞれのサイズ感はArticleの要素と同等を想定。
### Article
これまで投稿した記事の一覧を日付の降順で表示。
各記事ごとにタイトル、軽い説明、その記事へのリンク（プレビューつき？）が書かれた要素をグリッドで表示する。
現在の投稿はQiitaのみ。

最初はハードルコードでもいいが最終的にはQiitaからこのテンプレートで自動でとってこれる形にしたい。

Topicsに持ってきたいのでそれぞれのサイズ感はWorksの要素と同等を想定。
### Stack
技術スタックを、Languages、Frameworks & Platforms、Tools & Othersでまとめる。
それぞれを技術アイコン、技術名、どの程度できるか簡易的に記述する。
おそらく並びはflexboxを使用することになる。
Worksのようにクリックすることでより詳細な実績や経験を述べる拡大表示をつくるか、そもそもで説明をガッツリつけるか検討中。
### Profile
#### About me
私についての詳細。
テーブルで記述。
#### Activities
活動履歴についてテーブルで日付と活動内容を日付の降順で記述。
### Links
SNSリンクなどを記述。
X,Qiita,メールアドレス
## デザイン案
BlueProtocolをリスペクトする。

剣と魔法の世界で鎧まとってたたかってる中に超文明の技術が流れ込んだ世界。
SFとファンタジーの融合。
### デザイン研究
#### 色について
- 背景（公式サイト、公式の発表資料）：白
- 基本の文字（公式サイト、公式の発表資料）：黒
- 補足的な意味合いの文字（公式サイト、公式の発表資料）：薄い灰色
- 強調表示（公式サイト、公式の発表資料）：水色でマーカーっぽいライン
- ESCキー（ゲーム内）：オレンジ
- 注意書き、強調表示（ゲーム内）：黄緑
- 帯をつける際に紺色の帯に白文字という運用があった（公式サイト、公式の発表資料）
#### 装飾
- ヘッダー等に当たる内容に対して細めの下線（公式サイト、公式の発表資料）
- 要素ごとに区切るものとして細めの銀の線（ゲーム内）
- 端に特に意味はないが関わりのある文字が薄い色で書かれている（公式サイト、公式の発表資料）
- 端にゲーム内の風景が薄く配置されている（ゲーム内の風景は今回使わない）（公式サイト、公式の発表資料）
- 背景に斜めの線が入っている（公式サイト、公式の発表資料）
- 端に神殿等に掘ってありそうな模様が薄い色で刻まれていることもある（ゲーム内）
- 英語（もしくは記号）｜日本語で補足だったりそのまま訳等の装飾がある（ゲーム内）
- 文字——-で区切るデザインもある（ゲーム内）
- カーソルを合わせた際の補足のブロックの左端は何かしらの色が帯？みたいについている（ゲーム内）
- 細かいテキストの裏に薄め（拡大したり注目したら気づくレベルで）マークが書かれてたりする（ゲーム内）
#### アニメーション
- []が広がってその中に文字が出てくる→端から長めで背景色追加（区切る感じの演出つき）→左側で上から文字が落ちてくる（公式サイト、公式の発表資料）
- 新しく何かを表示させるときは黒背景に白のラインが中央から広がるか外から生えてくる形で区切りの線を出したりする（ゲーム内）
- ポップアップ？の演出として項目名が左から流れてくる、詳細が右から流れてくることもある（ゲーム内）
- アイコンの周りで円を描く＋真ん中から×を走らせて表示（ゲーム内）
- 下から透明度上げながらのポップアップ（ゲーム内）
- 右下から左上にかけて光の粒？がふわふわ飛んで行っているアニメーション（ゲーム内）
### 考察
全体的に細い線を多用する、設計図とか神秘的な彫刻？とか意識させるデザインやアニメーションが多い。
動かないものの部分ではハンコや紙、羊皮紙、木目、宝石等の中世の要素を多く感じる。
>BlueProtocolの世界観（惑星レグナス）：卓越した文明力を持ったバファリア神族が人類を作りその後地上を去る。残された人間たちはバファリアの遺産を活用しながら中世レベルの暮らしを行っている。人の文明レベルは中世なので遺産を完全に理解して活用できているわけではない。ルーツは不明だがエングラムという魔力のようなものがあり人々は魔法のようなものも使える。SF×中世ファンタジー。

神族と呼ばれているようにバファリア教というバファリア神族とその伝説を信奉する宗教がある。
おそらく、いたるところで見られる神秘的、宗教的、設計図的な模様はここにルーツがある。

また全体的に、神族が人を作り、人々はその遺産を活用しながら生活しているという経緯を表現するかのように、SF、神話チックなデザインの上に中世ファンタジーのデザインがのせられたようなテーマとなっている。

レグナスで生きている人の視点に立つとそれは少し違うのかもしれない。
バファリアの遺産はある意味ではドラえもんの秘密道具のような立場では？
そのルーツが今後たどり着く未来のものか、すでに失われた過去の技術かという違い。
そう考えるとSFが根底にあるというのを強調しすぎるより、スチームパンクが混ざった中世ファンタジーの中に明らかに文明レベルの違う技術が紛れ込んでいるというデザインの方が自然？。

公式の資料がブルプロらしいのはそりゃ公式が出しているものなんだから当たり前。（どんなデザイン出してきたってそれが元なんだし）
あまり公式の発表資料にとらわれない方がいいのかも。
### 活用
情報分野における偉大な先人たちが作った技術（プログラミング言語や設計思想等）をバファリアの遺産のような立ち位置でデザインに組み込む。
そして私の活動はバファリアの遺産があるレグナスの冒険者がそれを解析、活用した結果の記録として中世ファンタジーの立ち位置で組み込む。

テクノロジーは神秘的に、私に関わるものは中世ファンタジーで。

CSS、JavaScriptを使い体験を損ねないようにしながらもBlueProtocolのようなアニメーションや演出をマシマシにする。

## 方針
- 公式が使っている色は気にしない。
- レグナスの冒険者が書いた開拓局への報告書のイメージでつくる。
- 手紙、設計図、記録、みたいな感じ。
- sectionタイトルは記述しなきゃない既定のものというかみたいな感じでこの文章の媒体を作った側がハンコだったり指定してそれを量産しているイメージなのでIM Fell Englishを使用。
- 公的な記録はタイプライターとかで印字されたシステムチックなものなイメージなので、JetBrains Mono
- 記録？日記？手紙？みたいなものなので基本的な文字のフォントは手書き風なKlee Oneを採用。
